# 架构决策记录（ADR）

这里记录本项目的**重要架构决策**：引入依赖、改变目录结构、选型取舍、公共 API 变更等。

## 为什么要有它

AI Agent 和新人最容易犯的错是「不知道既有决策，凭直觉重做一遍」。ADR 提供可被读取的上下文，避免重复踩坑。

## 约定

- 编号从 `0001` 开始递增，文件名：`NNNN-短标题.md`
- 模板见 [`0000-adr-template.md`](./0000-adr-template.md)
- 状态流转：`Proposed` → `Accepted` → （可选）`Deprecated` / `Superseded by ADR-XXXX`
- 决策被推翻时，**不要删旧记录**，新增一条并标注取代关系
